# B. Homan Publications — Shopify theme

A custom Shopify Online Store 2.0 theme for B. Homan Publications.

## Connect to Shopify

1. In Shopify Admin, open **Online Store → Themes**.
2. Choose **Add theme → Connect from GitHub** (the label may vary).
3. Authorise Shopify to access GitHub if prompted.
4. Select repository **2mg8dz7c7h-web/B.Homan-Publicatons** and branch **main**.
5. Add the connected theme to your theme library and preview it before publishing.

## Theme structure

- `layout/theme.liquid` — storefront layout
- `templates/` — JSON page templates
- `sections/` — editable Shopify sections
- `assets/` — stylesheet and JavaScript
- `config/` — theme editor settings

## Editing

Use **Online Store → Themes → Customize** to edit homepage copy, publication cards, images, colours, navigation and section order.

Publication names and descriptions are initial proposed content. Review and update them before launch. The homepage cards currently introduce the proposed editorial portfolio; add dedicated Shopify pages and connect each card to its page when those divisions are ready.

Products, checkout, customer accounts and store policies are managed in Shopify. The contact form uses Shopify's built-in contact form.

## Before publishing

- Add your logo and any approved photography.
- Create and connect the navigation menu.
- Create About, Publications and Advertising pages as required.
- Configure store currency, shipping, tax and payment settings.
- Add privacy, terms and refund policies.
- Test the contact form, cart and checkout in preview.

This repository contains a Shopify theme, not a standalone HTML site.
